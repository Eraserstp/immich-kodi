Неофициальный аддон Kodi для просмотра фотографий и видео из
[Immich](https://immich.app).

## Требования

- Kodi 19 (Matrix) или новее (`xbmc.python` 3.0.0).
- Immich 3.x; аддон протестирован на Immich 3.3.3. Для старых серверов есть
  откат на устаревший API, но основная цель — Immich 3.x.
- Сетевой доступ с устройства Kodi к серверу Immich.

## Установка

1. Получите аддон в виде ZIP-архива (`plugin.video.immich-<version>.zip`).
2. В Kodi откройте **Дополнения → Установить из ZIP-файла** и выберите архив.
3. Откройте настройки аддона и заполните:
   - **URL Immich с http(s)://** — например `http://YOUR_IMMICH_HOST:2283`;
   - **API-ключ Immich** — создайте его в Immich в разделе
     **Настройки пользователя → API Keys**.
4. При необходимости измените формат отображаемого имени и время жизни кэша.

## Возможности

- **Хронология** — просмотр библиотеки по месяцам, фото и видео вместе.
- **Видео** — та же хронология, только видео.
- **Альбомы** — просмотр альбомов и их содержимого.
- **Альбомы по хронологии** — альбом открывается как список дат (дней), затем
  показываются только файлы выбранного дня.
- **Теги** — просмотр файлов по тегам. Теги без единого файла скрываются.
- Автоматические превью, сортировка по дате и локализованные подписи дат.
- Интерфейс на английском и русском языках.

## Отличия от базового проекта

Перечисленные изменения сделаны под моим контролем.

### Совместимость с API Immich 3.x

- Модели данных допускают отсутствующие и неизвестные поля, которые возвращают
  новые версии Immich.
- Файлы альбома загружаются через `POST /api/search/metadata`, если сервер
  больше не включает их в ответ альбома.
- Поиск использует актуальный объект `filter` и курсорную пагинацию с откатом
  на старые параметры `albumIds`/`tagIds`/`page` для Immich < 3.2.
- Хронология включает файлы партнёров через `withPartners=true` и корректно
  откатывается на собственные файлы, если сервер не поддерживает параметры.
- В альбомах для перекодированных видео используется `video/playback`, а для
  изображений — оригинальный медиафайл.

### Новые режимы просмотра

- Добавлен пункт меню **Альбомы по хронологии**: альбом → список дат по дням →
  файлы выбранного дня.
- Добавлен просмотр по тегам, загрузка файлов тега и скрытие тегов без файлов.

### Производительность

- Добавлен постоянный дисковый кэш API в профиле аддона с настраиваемым TTL
  (по умолчанию 300 секунд) и LRU-вытеснением (1000 файлов / 256 МБ).
- Большие месяцы хронологии и альбомы загружаются пакетно через
  `/api/search/metadata`, а не отдельным запросом `/api/assets/{id}` на каждый
  файл. Месяц на 3352 файла в локальном тесте открывается примерно за 0,4 секунды
  вместо ~140 секунд.
- Для превью в списках запрашивается маленький размер `thumbnail`, а видео
  получают метаданные длительности и разрешения, чтобы Kodi не пытался читать
  большие потоки при построении списка.

### Локализация

- Каталоги строк на английском и русском языках.
- Локализованные summary, description и news аддона в `addon.xml`.

### Настройки

- Добавлена настройка **Время жизни кэша, секунды (0 — отключить кэш)**.
